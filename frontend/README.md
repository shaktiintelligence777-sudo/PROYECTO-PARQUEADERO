# Frontend

React 18 + TypeScript estricto + Vite + Tailwind (tokens del design system) + HashRouter + TanStack Query.

```bash
npm ci
npm run dev
npm run lint && npm run typecheck && npm test && npm run build
```

Variables (`.env.example`): `VITE_API_MODE` (`mock`|`live`), `VITE_API_URL`, `VITE_BASE`.
Alias `@/` apunta a `src/`. Reglas para constructores: `CLAUDE.md`.
