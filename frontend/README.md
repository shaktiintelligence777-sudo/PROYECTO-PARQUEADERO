# Frontend (demo)

React + TypeScript + Vite + Tailwind. Por defecto usa una **API simulada** que guarda datos en `localStorage`.

```bash
npm ci
npm run dev        # http://localhost:5173
npm test && npm run lint && npm run typecheck
```

Demo: `demo@parqueadero.app` / `demo1234`. `VITE_API_MODE=mock|live` (live: pendiente, C-01).
Para activar Pages: Settings → Pages → Source: GitHub Actions.
