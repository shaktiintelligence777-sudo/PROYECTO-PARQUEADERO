# PROYECTO-PARQUEADERO

Aplicación web para un parqueadero de motos: membresías de clientes, notificación de fechas de pago, registro de entradas y salidas, y almacenamiento seguro en SQL.

- Frontend: SPA en GitHub Pages (login con email y contraseña).
- Backend: Python (FastAPI) + PostgreSQL.
